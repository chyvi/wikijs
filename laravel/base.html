Cron (планировщик в Laravel) задачи по расписанию

Основная статья  здесь https://laravel.su/docs/11.x/scheduling

В целом, алгоритм такой: на сервере в crontab ОДИН раз прописываем:

* * * * * cd /path-to-your-project && php artisan schedule:run >> /dev/null 2>&1

Остальное уже настраивается в /routes/console. Там доступны через встроенные в Laravel функции вызова по расписанию, с условиями, с передачей параметров, с постановкой в очередь, команды системы вроде exec и т.д. Очень гибкая система, поддерживающая множество разных вариантов.

Пример вызова метода send_user_push путём передачи в консоль соответствующей команды через Artisan каждые 30 минут с 8 до 20 часов по Самарскому времени:

use Illuminate\Support\Facades\Schedule;
//рассылка пушей в приложении для клиентов
Artisan::command('send_user_push', function () {
   $firebase = new Firebase();
   $firebase->send_user_push();
});
Schedule::command('send_user_push')
   ->everyThirtyMinutes()
   ->timezone('Europe/Samara')
   ->between('08:00', '20:00');

Через Artisan::command можно задать возможность вызова функции через терминал. Но в приведённом выше примере можно из без этого, работать будет. Причём, Artisan::command( some_code )→hourly(); тоже работающий вариант.

Список работ со следующим выполнением можно посмотреть в терминале через команду php artisan schedule:list

На сервере для планировщика (крона) созданы папки app/Models/Crone для моделей и app/Http/Controllers/Crone для контроллеров
