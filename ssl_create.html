1. Зайти на сервер по SSH.
  2. Открыть конфигурацию nginx, стандартный путь для конфигурации /etc/nginx/sites-available.
  3. Желательно объединить корневой сертификат и сертификат для домен, что бы браузеры не выдавали предупреждения.
  4. В конфигурации проверить/добавить/изменить путь к сертификату ssl_certificate и  ssl_certificate_key.

server {

    listen 443 ssl;

    listen [::]:443 ssl;

    server_name default_server;

    ssl_certificate /etc/ssl/jacodriver.crt;

    ssl_certificate_key /etc/ssl/jacodriver.key;

    ssl_session_cache   shared:SSL:10m;

    ssl_session_timeout 10m;

}

4. Заменить файлы сертификатов в папке /etc/ssl/

5. Проверить работоспособность конфигурацию nginx 

nginx -t

6. Перезапустить nginx 

systemctl restart nginx

7. Дополнительно сертификат можно проверить сервисом SSL checker
