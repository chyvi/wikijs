1. Добавление нового пользователя

1.1. В Администрирование перейти в раздел Пользователи;

1.2. Нажать кнопку + New User;

1.3. В окне ввести email, pass, имя, и принадлежность к группы. Нажать кнопку Create and Close.

2. Управление группами 

2.1. В Администрирование перейти в раздел Группы;

2.1. Для создание новой группы нажмите + New Group; В новом окне введите название и нажмите Create;

2.2. Для редактирование в списке группы выберите группу, которую ходите редактировать.

2.3. Настройки группы состою из четырех вкладок: settings, permission, page rulse, users.

2.3. В разделе settings, можно изменить название и страницу входа.

2.4.  В разделе permission,  можно назначить разрешения для группы пользователей: чтение и редактирование контента и другое.

2.5.   В разделе page rulse,  можно детально настроить права по каждому действию.

2.6. В разделе users,  можно добавить и удалить из позволившей из группы. Для добавления нажать на кнопку Assign User. В новом окне ввести почту пользователя. Для удаления пользователия из группы. Необходимо в строке пользователя нажать на 3 точки и выбрать Unassign.

2.7. После изменения параметров группы, необходимо нажать кнопку Update Group для сохранения имений.

2.8. Дополнительная информация по настройке пользователей и групп доступна по ссылке.

3. Создание страницы

3.1. Нажать кнопку «Новая страница» в правом верхнем углу страницы

3.2. В появившемся окне выбрать язык статьи (текущая локаль по умолчанию)

3.3. Ввести полный путь к странице, которую нужно создать. Путь не должен содержать пробелов (вместо них следует использовать дефисы), точек и должен состоять из символов, разрешённых для URL-адресов. Не нужно добавлять косую черту в конце.

3.4. Нажать «Выбрать», чтобы продолжить.

3.5. Выбрать редактор. Wiki.js предлагает на выбор несколько видов редакторов:

  • AsciiDoc (семантический язык разметки, в первую очередь предназначенный для написания технической документации)
  • Code (базовый редактор необработанного HTML, не рекомендуется)
  • Markdown (легкий язык разметки с синтаксисом форматирования простого текста. Это фактический синтаксис для написания документации в крупных репозиториях кода, таких как GitHub.)
  • Visual Editor (Визуальный редактор идеально подходит для нетехнических пользователей, которые предпочитают прямое визуальное представление того, что они пишут). Данный редактор предпочтителен.

3.6. В следующем диалоговом окне ввести название, описание и теги для страницы.

3.7. Нажать «ОК» и сохранить страницу.

3.8. Дополнительная информация по созданию и редактированию страниц доступна по ссылке.
