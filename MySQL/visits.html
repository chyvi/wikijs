Нормализация источников (как заполняются source/medium/classifier)

Есть UTM →

source = utm_source (если пусто — можно ставить (utm)),

medium = utm_medium (если пусто — (utm)),

campaign/term/content — из соответствующих utm,

classifier = 'utm'.

 

Нет UTM, но есть gclid →

source = 'google', medium = 'cpc', classifier = 'gclid'.

 

Нет UTM, но есть yclid →

source = 'yandex', medium = 'cpc', classifier = 'yclid'.

 

Нет UTM/кликидов, но есть реферер →

Если домен содержит google.*/yandex.*/bing.* → source = google|yandex|bing, medium = 'organic', classifier = 'ref-organic'.

Любой другой внешний домен → source = <ref_host>, medium = 'referral', classifier = 'referral'.

 

Нет реферера (или он внутренний) →

source = 'direct', medium = 'none', classifier = 'direct' (для внутреннего в коде можно ставить internal, но по отчётам это обычно «direct»).
